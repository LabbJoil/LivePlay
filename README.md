# LivePlay

Система лояльности отелей: мобильные приложения **(Android & iOS)** + серверная часть.

---

## 📌 Описание

LivePlay — это платформа, которая позволяет отелям создавать и управлять программами лояльности, а гостям — использовать удобные функции через мобильные приложения:

- Накопление бонусов, купонов и привилегий за пребывания и покупки.
- Проверка своего статуса, истории, баланса.
- Персонализированные предложения и акции.
- Сервер обеспечивает безопасность, синхронизацию данных, API для приложений.

---

## 🧩 Компоненты

Проект разбит на несколько ключевых частей:

| Компонент | Назначение |
|-----------|------------|
| **LivePlay.Front** | Мобильное приложение на .NET MAUI для Android/iOS. |
| **LivePlay.Server** | Серверная часть на .NET 8.0: API, бизнес-логика, интеграция с PostgreSQL. |
| **PostgreSQL**        | Хранилище данных о пользователях, транзакциях и программах лояльности. |
| **Docker/Docker Compose** | Контейнеризация и простое развёртывание. |
| **LivePlay.sln**      | Решение для Visual Studio / Rider, объединяющее все части проекта. |

---

## ⚙️ Основной функционал

- 🔑 Регистрация и авторизация пользователей.
- 🏨 Управление программами лояльности для отелей (уровни, бонусы, купоны).
- 📂 История транзакций: начисления/списания бонусов, получение и использование купоном.
- 👤 Профиль пользователя и персонализация.

---

## 🚀 Установка и запуск
1. Клонировать репозиторий.
2. Установить зависимости для серверной части (.NET 8.0 SDK, PostgreSQL).
3. Настроить строку подключения к базе данных.
4. Применить миграции базы данных.
5. Запустить сервер напрямую или через Docker.
6. Собрать и запустить мобильные приложения (Android/iOS) в .NET MAUI.

---

## 🔧 Стек технологий
- Backend: .NET 8.0 (ASP.NET Core Web API)
- Frontend (Mobile): .NET MAUI (Android/iOS)
- База данных: PostgreSQL
- ORM: Entity Framework Core
- Контейнеризация: Docker, Docker Compose

---

## 📂 Структура репозитория
- LivePlay.Front - MAUI приложение (Android/iOS)
- LivePlay.Server - Сервер на .NET 8.0 + EF Core
- docker-compose.yml - Запуск сервера и БД через Docker
